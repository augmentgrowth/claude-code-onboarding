# 04_Archives

The attic. Finished projects, inactive areas, and anything you're done with but not ready to throw away. Archiving beats deleting: it keeps your active folders clean while everything stays findable if you ever need it again.

**Example:** when the kitchen renovation wraps, the whole `kitchen-renovation/` folder moves here from `01_Projects`.

**Try this — say to Claude:** "Is anything in my 01_Projects folder finished or stale? Suggest what could move to 04_Archives — but don't move anything without asking me."

Note the name: `04_Archives`, plural. Setup checks look for exactly this spelling, so don't rename it.
