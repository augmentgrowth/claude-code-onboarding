# 01_Projects

Active work with a finish line. A project is something you're pushing forward right now that will someday be *done* — then it moves to `04_Archives`. Each project gets its own subfolder so everything about it lives in one place.

**Example:** `01_Projects/kitchen-renovation/` holding quotes, a budget note, and a to-do list.

**Try this — say to Claude:** "Help me start a project folder for [something you're working on] with a short README and a next-actions list."

There's already one folder here: `_sample_project_rescue/` — a fake messy project you can practice on. See its SAMPLE_README.md.
