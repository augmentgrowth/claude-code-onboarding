# PARA Guide

PARA is the filing system this vault uses: Projects, Areas, Resources, Archives — plus an Inbox for things you haven't sorted yet.

- `00_Inbox`: temporary capture; process later.
- `01_Projects`: active work with a finish line.
- `02_Areas`: ongoing responsibilities.
- `03_Resources`: reusable references, templates, examples, and learning.
- `04_Archives`: completed or inactive material.

Decision: active goal -> Projects; ongoing responsibility -> Areas; reusable info -> Resources; unclear -> Inbox; inactive -> Archives.
Ask before large reorganizations. Archive instead of deleting.
