# 03_Resources

Reference material — things you keep because they're useful, not because they're tied to one project. Templates, how-to notes, articles worth saving, examples you might reuse. When a project ends, its reusable pieces often graduate here.

**Example:** `03_Resources/recipes/` or a `meeting-notes-template.md` you copy for every meeting.

**Try this — say to Claude:** "Turn this note into a reusable template and save it in 03_Resources."
