# 00_Inbox

This is the catch-all. Anything you capture in a hurry — a thought, a link, a half-formed idea — lands here first, and you sort it later. An inbox only works if adding to it is effortless, so never stop to decide where something "really" belongs.

**Example:** a file called `call-with-plumber.md` with three lines of notes, dropped here mid-day, sorted on Friday.

**Try this — say to Claude:** "Look at what's in my 00_Inbox and suggest where each item should go."

Empty is the goal, but a full inbox is still better than notes scattered across your desktop.
