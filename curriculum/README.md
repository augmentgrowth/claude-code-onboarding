# Curriculum

The module procedures the setup skill runs, one file per module, in the canonical ladder order M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M10 → M9 → M11: `m00-start-here.md` (orientation and the verify-first habit), `m01-get-claude.md` (settings, the terminal command), `m02-your-vault.md` (verify and tour the built vault), `m03-first-win.md` (rescue a real folder; the one reopen), `m04-connect-tools.md` (one connector, proven), `m05-personalize-claude-md.md` (the three context files), `m06-organize-with-para.md` (the five folders and the decision tree), `m07-github-backup.md` (private backup, privacy review first), `m08-real-workflows.md` (three real workflows), `m10-skills-advanced-tools.md` (power features one at a time), `m09-routines.md` (one routine, manual first), and `m11-mobile-sync.md` (notes on the phone, one recommended path). Alongside the modules: `receipts.md` (how the setup receipt is verified, filled, approved, and sent) and `troubleshooting.md` (the mid-setup cards: can't-type/Git, a cautious assistant, conflicted copies, and the adaptation contract). Each module file opens with a short note for the person being set up, then the agent-facing procedure: steps, approval gates, the verification check by its registry ID, and what to record in the ledger.
